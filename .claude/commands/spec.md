# SPEC.md参照

SPEC.mdの特定セクションを参照します。

## 使用方法

引数: $ARGUMENTS

## 実行内容

1. SPEC.mdを読み込む
2. 引数で指定されたセクション番号に基づいてフィルタリング
3. 該当セクションの内容を表示

## セクション番号の形式

- `4.3.1` - Location API仕様
- `3.3` - データモデル全般
- `8.1` - 認証設計
- `6.1` - 開発環境

## 実行手順

1. まず SPEC.md を読んでください
2. 引数 `$ARGUMENTS` がある場合:
   - セクション番号（例: `4.3.1`）として解釈
   - 該当セクションを抽出して表示
3. 引数がない場合:
   - SPEC.mdの目次（セクション一覧）を表示

## 注意事項

- セクション番号は `§ X.X.X` の形式で記載されています
- サブセクションも含めて表示してください
- 関連するセクションがあれば、参照先として提示してください
