# CLAUDE.md参照（コーディング規約）

CLAUDE.mdのコーディング規約を参照します。

## 使用方法

引数: $ARGUMENTS

## キーワード例

- `constants` - マジックナンバー禁止、定数管理ルール
- `messages` - エラーメッセージ一元管理
- `service` - Service層パターン
- `naming` - 命名規則
- `jsdoc` / `docstring` - ドキュメントルール
- `test` - テスト戦略
- `typescript` / `python` - 言語別規約
- `skills` - スキル一覧

## 実行手順

1. CLAUDE.md を読む
2. 引数 `$ARGUMENTS` があれば該当セクションを抽出して表示
3. 引数がなければ主要セクション一覧を表示
