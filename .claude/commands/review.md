# 変更レビュー

現在の変更内容をレビュー形式で表示します。

## 使用方法

引数: なし

## 実行手順

1. `git status --short` で変更ファイル一覧取得
2. `git diff --stat` で変更サマリー取得
3. 主要変更ファイルの内容確認
4. SPEC.md/CLAUDE.md準拠チェック:
   - 命名規則
   - JSDoc/Docstring
   - マジックナンバー
   - エラーメッセージ一元管理
   - Service層パターン
5. レビュー結果を報告（良い点・改善点・推奨アクション）

## 注意

- untracked（新規）ファイルも含める
- テストコードの有無も確認
