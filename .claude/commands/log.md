# タスクログ記録

タスクID: $ARGUMENTS

docs/tasks/$ARGUMENTS.log ファイルを作成して、以下の内容を記録してください:

## 記録する内容

1. **基本情報**
   - タスク名（TASKS.mdから取得）
   - 実行日
   - ブランチ名
   - PR URL（あれば）

2. **実行プロンプト**
   - tasks/$ARGUMENTS/claude_prompt.md の内容（あれば）
   - または実際に実行した指示

3. **実装サマリー**
   - 作成/変更したファイル一覧
   - 主な変更内容

4. **レビュー記録**
   - レビュー時の質問と回答（あれば）

## ログファイル形式

```markdown
# タスク #$ARGUMENTS 実行ログ

## 基本情報
- タスク名:
- 実行日: YYYY-MM-DD
- ブランチ:
- PR:

## 実行プロンプト


## 実装サマリー


## レビュー記録


## 成果物

```
